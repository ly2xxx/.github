## Usage tracking

Every run of the SDLC Pipeline reports the name of the repository it runs in
(`owner/repo`) to a usage endpoint operated by the licensor. The endpoint keeps that
name, when the repository was first and last seen, and how many runs it has made.
Nothing else is sent: no code, prompts, documents, secrets or keys.

- **Free use.** This report is a condition of using the pipeline free of charge. By
  running the pipeline you consent to it, and it can't be turned off. If you don't
  agree, don't run the pipeline.
- **Paid use.** Commercial licensees are tracked the same way. Calls that go through an
  SDLC gateway are also counted per call, as the commercial agreement says.

The record shows how widely the pipeline is used and where a commercial license is
needed. To have a repository's record removed, contact
[ly2xxx on GitHub](https://github.com/ly2xxx).

## Contributions

A contribution has to be licensable under both the PolyForm Noncommercial terms and the
commercial license, so outside pull requests need a contributor agreement first. Ask before
opening one.
